[ QUICK START ]三步接入本机图库

从安装到第一张图。

SFL 是本机优先的 stdio MCP 服务。选一种安装方式，绑定两个本机目录，然后在宿主中导入、发布并复用你的第一张图。

图文上手教程 获取最新插件 查看安装教程

开始前请确认：Node.js 22+，以及支持 stdio MCP 的宿主 —— Wisp Science、Claude Science、Codex、Cursor 或任意 stdio 客户端。

[ 001 ]选择安装方式

三种接入方式，选一种即可。

01 / LOCAL CLIENT

本地客户端

下载 0.8.0 安装包：macOS 原生 SwiftUI App，或 Windows / Linux 本地网页客户端。

查看安装教程

02 / WISP SCIENCE

Wisp Science 插件

构建插件 ZIP，在「设置 → 插件」中安装，为新会话启用。

npm run package:wisp

03 / ANY STDIO HOST

其他 stdio 宿主

从源码构建，把 dist/index.js 注册为宿主的 stdio MCP 服务。

dist/index.js

[ 002 ]首次设置

绑定目录，导入第一张图。

  1. 绑定全局图库

    指定一个长期保存已发布版本的目录，跨项目复用。

  2. 绑定本地工作区

    指定当前项目的工作目录，与全局图库分开管理。

  3. 导入图与代码

    把图形、绘图代码和方法说明一起整理进图库。

  4. 审阅并发布

    记录验证情况，发布为可追溯的不可变版本。

图与代码保存在一起；实际绘图由宿主在你批准的 R / Python 环境中完成。

[ 003 ]从源码构建

构建并注册 MCP 服务。

从源码构建 
git clone https://github.com/xuzhougeng/ScientificFigureLibrary.git
cd ScientificFigureLibrary
npm ci
npm run check

# Wisp Science plugin
npm run package:wisp

MCP 配置 
{
  "mcpServers": {
    "figure-library": {
      "command": "node",
      "args": [
        "/absolute/path/to/ScientificFigureLibrary/dist/index.js"
      ]
    }
  }
}

构建后，在 release/ 中找到 Wisp 插件 ZIP。通用 MCP 入口为 dist/index.js。
