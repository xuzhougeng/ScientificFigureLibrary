# FigureYa-style writing patterns

Learn the question-first structure, not the exact sentences or overstrong causal claims. FigureYa examples include a gene-family tree/expression/alignment comparison asking how unknown genes relate to a known family, and a Sankey diagram showing mutation distributions across subgroups. These are writing patterns, not proof that a chart establishes function or causality.

## Weak → useful

- Weak: "A bubble plot showing NES with size and transparency."
- Useful: "When comparing treatment and control transcriptomes, summarize already-computed GSEA results to see which gene sets enrich toward either end of the ranked list and prioritize processes for follow-up. Interpret NES relative to the ranking direction rather than as proof of functional activation."
- Weak: "A tree with black, grey and white points."
- Useful: "After phylogenetic inference, show branching relationships together with their support levels so a reader can identify which relationships need cautious interpretation. For a candidate clade, inspect the relevant node support instead of treating visual grouping alone as confirmation."

## Review rubric

Does the text identify a biological comparison or question? Does it say when a researcher would choose this template? Are visual mechanics separate from purpose? Are data claims supported by the inspected assets? Does any sentence invent an original result or claim certainty the plot cannot supply? Is any paragraph repeated unnecessarily? Keep enough context to choose the figure, not a full installation or reproduction tutorial.

A source-free example remains a general scenario. Real source-backed facts need the source's actual figure/legend/results, not a matching chart type alone.
