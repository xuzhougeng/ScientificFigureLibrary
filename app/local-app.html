本机目录

图片、代码及参考缓存统一保存在图库存储位置下，跨项目复用。请使用绝对路径。

系统代理

访问 GitHub 清单和预览图时，可走本机回环 HTTP 代理（CONNECT）。目标仍是 GitHub 的 HTTPS 地址，下载后按 SHA-256 校验。默认不使用系统代理，以免 Clash fake-ip（如 198.18.x）被当成目标地址。

图片缓存

安装不会下载在线图库图片。请前往「连接外部图库」选择图库并点击「缓存图片」；搜索该图库的当前页或打开精确预览也会写入同一目录。「我的图库」不需要这一步。清除后需重新缓存或再次查看；已确认图片需重新预览再保存模板。
